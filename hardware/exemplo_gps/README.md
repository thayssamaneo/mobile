# exemplo_gps

A new Flutter project.

## Instalação e configuração da biblioteca GeoLocator

Acessa pub.dev

**Ler documentação da biblioteca a ser utilizada**

- geolocator

### Como usar:
1. Instalar a biblioteca no projeto:
```bash
flutter pub add geolocator
```
2. Habilitar o uso do geolocator no AndroidManifest.xml (android/app/src/main)
3. Usar a biblioteca

---

> <small>OBS: Antes do primeiro uso do GPS, é necessário habilitar o serviço de GPS pelo APK (fazer usando código)<small>
